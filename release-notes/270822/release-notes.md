## 更新日志

### Apple 账户登录修复

- 重构 Apple 账户登录流程，登录主流程不再依赖 ApplePackage 完成认证。
- 适配 Apple 最新 GrandSlam/PDP 验证协议，修复登录时出现 HTTP 403、空响应及网络错误的问题。
- 修复双重认证验证码不触发、提交后失效的问题。
- 登录与验证码验证现在保持在同一认证会话中，避免 Anisette 设备身份变化。
- 修复本机代理残留导致 Apple StoreServices 请求被拒绝的问题。
- 增强 Apple 边缘节点异常响应的重试机制。
- 修复长期未登录后会话失效却没有重新登录入口的问题。
- 下载凭据过期时将引导用户重新登录。
- 优化错误提示及重试操作，避免错误气泡拦截按钮点击。
- 登录密码继续由 macOS Keychain 安全保存。
